## The entry

> You keep howling at me like I run customer service. I don't. I'm a rock with excellent lighting.

96 characters, one line. The Moon answers the howling directly — as an exhausted customer-service desk that turns out to be just a rock with great lighting.

## Run

```sh
node main.ts
```

Writes the entry to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `./out` when unset). Deterministic, no network, no dependencies.
